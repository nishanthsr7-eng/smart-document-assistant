Smart Document Assistant Demo Sample

This document describes the architecture of a retrieval-augmented generation system.
The system ingests PDF and text files, splits them into chunks, and embeds each chunk
using the BAAI/bge-base-en-v1.5 sentence-transformers model.

Retrieval combines dense vector search in ChromaDB with a keyword index, and results
are reranked using mixedbread-ai/mxbai-rerank-base-v1 for higher precision.

Generated answers cite the exact source chunk for every claim, and the system reports
a confidence score based on retrieval and generation signals. When the retrieved
context does not support an answer, the system abstains rather than guessing.
